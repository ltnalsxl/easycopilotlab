## 이 모듈에서 배우는 것

- **커스텀 커넥터**란 무엇인지 — 기본 커넥터에 없는 외부 서비스 연결

- **OpenAPI 정의**로 커스텀 커넥터 등록
- 에이전트에서 커스텀 커넥터를 **도구로 호출**하는 실습

## 기본과정에서는

기본과정 M11에서 **기본 커넥터(Excel 행 추가)**를 사용했습니다.

| 기본 커넥터 | 커스텀 커넥터 |
|:-----------|:-------------|
| Microsoft가 미리 만들어 놓은 것 | **내가 직접 등록하는 것** |
| Excel, Outlook, Teams 등 | 어떤 외부 API든 가능 |
| 클릭 몇 번으로 연결 | OpenAPI 정의 필요 |

{: .highlight }
> 기본 커넥터에 원하는 서비스가 없으면? **커스텀 커넥터**로 직접 연결합니다.

## REST API = 질문과 답변

REST API는 어렵게 느껴지지만, 본질은 **질문과 답변**입니다.

```
에이전트: "서울 날씨 어때?" (GET /weather?city=seoul)
    ↓
날씨 API: "맑음, 18도입니다" (JSON 응답)
    ↓
에이전트: "서울은 현재 맑고 18도입니다"
```

| 일상 대화 | REST API |
|:---------|:---------|
| "서울 날씨 알려줘" | GET /weather?city=seoul |
| "맑음, 18도" | `{"weather": "맑음", "temp": 18}` |

{: .tip }
> REST API는 **컴퓨터끼리 대화하는 약속**입니다. 사람이 한국어로 대화하듯, 컴퓨터는 URL과 JSON으로 대화합니다.

## OpenAPI 정의 = 설명서

커스텀 커넥터를 만들려면 **API 설명서(OpenAPI 정의)**가 필요합니다.

### OpenAPI 정의가 담는 정보

| 항목 | 설명 | 비유 |
|:-----|:-----|:-----|
| 서버 주소 | API가 어디에 있는지 | 전화번호 |
| 엔드포인트 | 어떤 기능이 있는지 | 메뉴판 |
| 파라미터 | 무엇을 보내야 하는지 | 주문서 |
| 응답 형식 | 무엇을 받게 되는지 | 배달 목록 |

{: .note }
> OpenAPI 정의 파일은 **사전 제공**합니다. 직접 작성할 필요 없습니다.

## 실습: 환율 API 커스텀 커넥터

공개 환율 API를 커스텀 커넥터로 등록하고, 에이전트에서 호출합니다.

### 시나리오

> 사용자: "오늘 미국 달러 환율 알려줘"  
> 에이전트: 환율 API 호출 → "현재 USD/KRW 환율은 1,350원입니다"

### 실습 흐름

```
① OpenAPI 정의 파일 확인 (사전 제공)
    ↓
② Power Platform에서 커스텀 커넥터 생성
    ↓
③ API 키 설정 (사전 제공)
    ↓
④ 테스트 탭에서 동작 확인
    ↓
⑤ Copilot Studio에서 도구로 추가
    ↓
⑥ 에이전트에게 "달러 환율 알려줘" 질문
```

### 커스텀 커넥터 생성 단계

| 단계 | 설정 | 값 |
|:-----|:-----|:---|
| 1 | 커넥터 이름 | ExchangeRate |
| 2 | 호스트 | API 서버 주소 |
| 3 | 인증 | API 키 |
| 4 | 동작 정의 | OpenAPI에서 자동 import |
| 5 | 테스트 | USD → KRW 조회 확인 |

---

## 에이전트에서 호출

커스텀 커넥터를 만든 후, Copilot Studio에서 **도구로 추가**합니다.

```
에이전트 설정 → 도구 → 커스텀 커넥터 추가
    ↓
오케스트레이터가 사용자 질문을 보고 자동으로 호출 판단
```

### STRICT RULES 추가 (선택)

```
## STRICT RULES
- 환율 관련 질문이 오면 반드시 ExchangeRate 커넥터를 호출하세요.
- "오늘 환율", "달러 환율", "엔화 환율" 등의 질문에 반응합니다.
```

## 커스텀 커넥터 활용 예시

| 외부 서비스 | 에이전트 활용 |
|:-----------|:-------------|
| 환율 API | "오늘 달러 환율 알려줘" |
| 날씨 API | "서울 내일 날씨는?" |
| 사내 API | "내 연차 잔여일 조회" |
| 택배 API | "운송장 번호로 배송 추적" |

{: .highlight }
> 커스텀 커넥터를 만들 수 있으면, 에이전트가 **어떤 외부 서비스든** 연결할 수 있습니다. 에이전트의 손이 무한히 늘어나는 것입니다.

## 기본 커넥터 vs 커스텀 커넥터

| | 기본 커넥터 | 커스텀 커넥터 |
|:--|:-----------|:-------------|
| 설정 난이도 | 클릭 몇 번 | OpenAPI 정의 필요 |
| 사용 가능 서비스 | Microsoft 365 + 인기 서비스 | **모든 REST API** |
| 인증 | 자동 | 수동 설정 |
| 유지보수 | Microsoft가 관리 | 내가 관리 |
| 적합한 경우 | 기본 제공 서비스 사용 | 사내 시스템, 특수 API |
