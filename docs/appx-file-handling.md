## 이 모듈에서 배우는 것

- 에이전트의 **“파일 업로드(파일 분석)”** 기능을 켜면 **어떤 일을 할 수 있는지**
- 같은 기능이 **어디서 막히는지(한계)** — 그래서 **왜 다음 모듈(S1·S2)이 필요한지**

{: .highlight }
> 기본과정 M8에서는 “지식”에 파일을 미리 올려두는 길을 봤습니다. 이 모듈은 다른 길 — **사용자가 채팅 중에 파일을 던져 넣고 그 자리에서 분석시키는** 기능에 집중합니다.

---

## 어떤 기능인가

- 위치: 에이전트 설정 → **파일 분석(File analysis)** 켜기
- 동작: 사용자가 채팅창에 파일을 **드래그&드롭** 하면, 오케스트레이터(LLM)가 **그 자리에서 파일을 읽고** 답변에 활용
- 지식과의 차이: 지식은 “미리 올려둔 고정 자료”, 파일 업로드는 “**그때그때 들어오는 일회성 자료**”

```
[지식]                              [대화 중 파일 업로드]
─────────────                       ─────────────────────
빌더 시점에 등록 → 인덱싱            대화 시점에 첨부 → LLM이 직접 읽음
같은 문서를 반복해서 묻는 용도        매번 다른 파일을 일회성으로 묻는 용도
```

### 활성화 위치

| 항목 | 설정 |
|:-----|:-----|
| 에이전트 설정 → **파일 분석** | 켜기 |
| 지원 형식(대표) | PDF, DOCX, PPTX, XLSX, TXT, 이미지(PNG/JPG) 등 |

---

## 켜면 사용할 수 있는 것

- **요약**: 처음 보는 PDF/Word를 끌어다 놓고 “3줄로 요약해줘”
- **항목 추출**: “이 계약서에서 종료일·금액·당사자만 뽑아줘”
- **표·시트 질의**: Excel을 던져 놓고 “영업1팀 인원 몇 명?”, “지점별 합계는?”
- **이미지 이해(비전)**: 화면 캡처·사진을 올리고 “이 차트 추세 설명해줘”
- **번역·재작성**: “이 보고서 한국어 → 영어 1페이지로”
- **후속 질문**: 같은 대화 안에서 “그럼 다른 항목은?” 같은 **연속 질문**
- **여러 파일 비교**: 두 문서를 같이 올리고 “차이점 정리”

> 핵심 가치 — **사용자가 굳이 빌더에 들어가지 않고, 채팅창에서 일회성으로 즉석 분석**할 수 있다는 점.

## 한계 — 어디서 막히는가

| 한계 | 설명 |
|:-----|:-----|
| **결과물이 답변뿐** | 채팅창 텍스트로만 나옴. Excel 행 추가, Word 보고서, 메일 발송 같은 **산출물 자동 생성은 불가** |
| **세션에서만 유효** | 대화가 끝나면 첨부 파일·답변은 사라짐. 다른 사용자나 다음 대화에 **재사용 안 됨** |
| **자동화 안 됨** | 사용자가 매번 **수동으로 업로드**해야 함. 메일 첨부·SharePoint 업로드를 **트리거로 받는 것은 별도** (S16 트리거 / 흐름 영역) |
| **다른 시스템 연동 약함** | 추출 결과를 그대로 Excel·Dataverse·CRM에 **밀어 넣는 경로 없음** |
| **정형 출력이 흔들림** | “JSON으로 줘”라고 해도 LLM 자유 답변이라 **스키마가 보장되지 않음** |
| **표·숫자 정확도** | 복잡한 Excel/스캔 PDF에서 **수치 정확도가 흔들릴 수 있음**. 큰 파일·많은 시트는 더 약함 |
| **파일 크기·개수 제한** | 한 번에 올릴 수 있는 **크기·페이지·개수**에 상한이 있음 |
| **거버넌스** | 사용자가 올린 파일이 **어디에 보존되는지·추적되는지** 별도 정책 확인 필요 |

## 시연 시나리오 (15분)

| 단계 | 내용 | 시간 |
|:-----|:-----|:----|
| 1 | 에이전트 설정에서 **파일 분석 켜기** 확인 | 1분 |
| 2 | 채팅창에 PDF 1장 드래그&드롭 → “3줄 요약” / “핵심 항목 5개” | 4분 |
| 3 | 같은 대화에 Excel 1개 추가 → “영업1팀 몇 명?” 같은 표 질의 | 4분 |
| 4 | 토론: "이 추출 결과를 **Excel 행으로 자동 추가**하려면?" → 답변만으로는 불가 → S1·S2로 자연 전환 | 6분 |

{: .important }
> 마지막 토론이 핵심입니다. **“답변만 필요하면 이걸로 충분, 산출물·자동화가 필요하면 다음 모듈”** — 이 한 줄을 남기고 S2로 넘어갑니다.

## 핵심 정리

> **파일 업로드 = 일회성·즉석 분석에는 강력. 자동화·정형 산출물·시스템 연동에는 부족.**

| 구분 | 대화 중 파일 업로드 |
|:-----|:------------------|
| 일회성 즉석 요약/추출 | ✅ |
| 같은 대화 안 후속 질문 | ✅ |
| 이미지·표 이해 | ✅ (정확도 한계 있음) |
| 채팅 외 **산출물 자동 생성** | ✗ |
| 세션 종료 후 **재사용** | ✗ |
| 외부 시스템 **자동 연동** | ✗ |
| **스키마 보장** 정형 출력 | ✗ |

이 한계 때문에 — 영수증을 Excel로, PDF를 Word로 흘려보내는 **다음 두 모듈은 “흐름 + AI 빌더 프롬프트”** 길을 선택합니다.
