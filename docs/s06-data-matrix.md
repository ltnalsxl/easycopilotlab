## 이 모듈에서 배우는 것

- 데이터를 두 축(**정형/비정형 × 지식/도구**)으로 보는 사고 틀
- 어느 칸에 어떤 기술이 들어가는지 — **매트릭스 한 장**으로 정리
- 다음 S7(Excel 케이스 스터디)에서 구체화할 결정 프레임 잡기

{: .highlight }
> 학습자가 마주하는 진짜 질문은 “Excel을 어떻게 다룰까”가 아니라 **“이 데이터를 지식 칸에 넣을까, 도구 칸에 넣을까”** 입니다. 이 모듈에서 답하는 방식을 잡고, S7에서 Excel 사례로 검증합니다.

---

## 두 축으로 데이터 다루기

### 축 1 — 데이터 모양

| 모양 | 예시 |
|:-----|:-----|
| **정형(Structured)** | Excel 표, CSV, SP 리스트, Dataverse, 사내 DB |
| **비정형(Unstructured)** | PDF/Word 문서, 메일, 이미지, 영상, 회의록 |

### 축 2 — 에이전트가 쓰는 길

| 길 | 동작 원리 |
|:-----|:---------|
| **지식(Knowledge)** | 미리 인덱싱 → AI가 의미 검색으로 답변 생성 |
| **도구(Tool)** | 흐름·커넥터·스크립트가 데이터를 직접 조회·기록 |

---

## 매트릭스 한 장

```
                    ┌────────────────────────┬───────────────────────────┐
                    │       지식(Knowledge)      │           도구(Tool)         │
─────────────┼────────────────────────┼───────────────────────────┤
                    │ ▲ 가능하지만 정밀 조회 약함  │ ◎ 자연스러운 길              │
   정형          │ · SP 리스트 지식            │ · Excel 커넥터              │
                    │ · CSV 업로드 (작은 표)     │ · SP 리스트                │
                    │                              │ · Dataverse                  │
                    │                              │ · CSV + AI 프롬프트         │
                    │                              │ · Office Script             │
─────────────┼────────────────────────┼───────────────────────────┤
                    │ ◎ 자연스러운 길               │ ▲ 가능하지만 결과가 비정형   │
   비정형      │ · 파일 업로드               │ · AI Builder 추출 프롬프트   │
                    │ · SP 파일/폴더             │ · 대화 중 파일 업로드 (S1 ②) │
                    │ · 웹사이트                 │                           │
                    └────────────────────────┴───────────────────────────┘
```

### 한 줄로

> **정형은 도구로, 비정형은 지식으로 — 가 기본 원칙. 단, 산출물(JSON·Word 등)이 필요하면 비정형도 “도구(AI Builder)”로 가야 한다.**

---

## 칸별 설명

### ① 정형 × 지식 — “가능하지만 약함”

| 무엇이 들어가나 | 한계 |
|:--|:--|
| SP 리스트를 지식 소스로 등록 | 의미 검색이라 “정확히 X열의 값” 같은 정밀 조회는 약함 |
| 작은 CSV/Excel을 직접 업로드 | 행 수가 많아지면 답변 품질 급락 |

→ **권장하지 않음.** 정형 데이터라면 다음 칸(도구)으로 가는 게 자연스럽습니다.

### ② 정형 × 도구 — “가장 자연스러운 칸”

| 기술 | 적합한 상황 |
|:--|:--|
| Excel 커넥터 (M12 / S7) | 작은 표, 단순 조건, 행 추가 |
| **CSV + AI 프롬프트 (S7)** | 작은 표, AI 분석·요약 필요 |
| **Office Script (S2 / S7)** | 큰 표, 정밀 필터·집계 |
| SP 리스트 | 권한 관리·뷰가 필요한 정형 데이터 |
| Dataverse | 엔터프라이즈급 관계형 데이터 |

→ S7에서 Excel을 케이스로 깊게 다룹니다.

### ③ 비정형 × 지식 — “자연스러운 칸”

| 기술 | 적합한 상황 |
|:--|:--|
| 파일 업로드 (M8) | 자주 묻는 같은 PDF/Word/매뉴얼 |
| SP 파일/폴더 (부록) | 자주 갱신되는 사내 문서 |
| 웹사이트 | 외부 공개 정보 |

→ 기본과정 M8에서 이미 학습한 길.

### ④ 비정형 × 도구 — “산출물이 필요할 때”

| 기술 | 적합한 상황 |
|:--|:--|
| **AI Builder 멀티모달 (S2)** | 영수증·명함 등 이미지에서 정형 추출 |
| **AI Builder 파일 입력 (S3)** | PDF 문서를 정형 텍스트/Word로 변환 |
| 대화 중 파일 업로드 (S1 ②) | 일회성 즉석 분석 |

→ S2·S3에서 이미 실습한 길. 결과물이 **산출물(JSON·Word·Excel)** 일 때 이 칸을 선택합니다.

## 결정 트리

```
이 데이터를 어떻게 다룰까?
    │
    ├─ 모양은? ──── 정형 ──────┐
    │                                                              │
    └─ 비정형 ─────────┐                              │
                                                                          │
                                  답변만 필요한가?                  │
                                              │                              │
                                  YES → ③ 지식 칸          │
                                  NO  → ④ AI Builder 칸  │
                                                                          │
                                                          정밀 조회 필요?
                                                              │
                                                  YES → ② 도구 칸
                                                  NO  → ② 도구 칸 (간단 커넥터)
```

> **정형은 거의 항상 ② 도구**, 비정형은 **③ 지식 또는 ④ AI Builder** 중 “산출물 유무”로 갈립니다.

---

## 자주 헷갈리는 케이스

| 시나리오 | 어느 칸? | 이유 |
|:---|:---|:---|
| 매주 들어오는 영수증 사진을 Excel 대장에 모은다 | ④ AI Builder | 비정형 → 정형 산출물(Excel 행) |
| 사내 사규 PDF에 “경비처리는 며칠 안에?” | ③ 지식 | 비정형 + 답변만 필요 |
| 자산 관리 Excel에서 “인프라팀 Linux 서버 목록” | ② 도구 | 정형 + 정밀 조회 |
| 한 번 받아본 제안서 1개 요약 | S1 ② 대화 업로드 | 비정형 + 일회성 |
| 오늘 환율 / 날씨 같은 외부 데이터 | ② 도구 (외부 API) | 정형 + 실시간 |

---

## 잘못된 길의 증상

| 증상 | 원인 칸 | 옮겨야 할 칸 |
|:-----|:-----|:-----|
| “AI가 표 행 수를 자꾸 틀려요” | ① 정형 × 지식 | ② 정형 × 도구 |
| “PDF 들어올 때마다 매번 일일이 분류해야…” | S1 ② 대화 업로드 | ④ AI Builder |
| “Word 보고서까지 자동으로 안 만들어져요” | ③ 비정형 × 지식 | ④ AI Builder |
| “문서가 자주 바뀌는데 답변이 옛날 내용이에요” | 파일 업로드 (③ 단발성) | SP 폴더 (③ 자동 갱신) |

---

## 핵심 정리

| 메시지 | 한 줄 |
|:-----|:-----|
| 가장 자주 쓰는 칸 | **②(정형 × 도구)** + **③(비정형 × 지식)** |
| 산출물이 필요한 칸 | **④(AI Builder)** — S2·S3 |
| 거의 안 쓰는 칸 | **①(정형 × 지식)** — 정밀도가 부족 |
| 다음 S7 | ② 칸을 **Excel 케이스 스터디**로 깊게 다룸 |

{: .important }
> 이 매트릭스를 머리에 넣고 다음 S7에 가면, “Excel × 지식 4가지 + 도구 3가지”가 단순 나열이 아니라 **한 칸을 다양한 기술로 채워보는 검증 사례**로 보입니다.
