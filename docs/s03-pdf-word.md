## 이 모듈에서 만들 것

> **PDF 문서 한 장 → AI가 핵심 정보 추출 → Word 템플릿에 채워 .docx 보고서 자동 생성**

S2에서는 입력이 **이미지**였다면, 여기서는 입력이 **파일(PDF)**, 출력이 **다른 파일(.docx)** 입니다. AI 빌더의 또 다른 길이지만 “정형 산출물이 필요해서 ③번 길을 쓴다”는 메시지는 동일합니다.

---

## 전체 흐름

```
📄 PDF 업로드 (제안서 · 계약서 · 보고서)
    ↓
🤖 AI 빌더 텍스트 프롬프트 (파일 입력)
   "정해진 포맷으로 핵심 정보 추출"
    ↓
📋 추출 결과 (제목 · 작성자 · 요약 · 항목 · 특이사항)
    ↓
📝 AI 빌더 Word 아웃풋
   Word 템플릿에 추출 결과 매핑
    ↓
📥 .docx 보고서 다운로드
```

---

## S2 vs S3 비교

| | S2 (영수증 → Excel) | S3 (PDF → Word) |
|:--|:------------------|:----------------|
| 입력 | **이미지** | **파일 (PDF)** |
| AI 빌더 유형 | 멀티모달 프롬프트 | **텍스트 프롬프트 (파일 입력)** |
| 산출물 | Excel 행 (구조화 행) | **Word 문서 (문서)** |
| 후속 시스템 | Office Script | **AI 빌더 Word 아웃풋** |

{: .highlight }
> S2는 “이미지 → 표의 한 행”, S3는 “문서 → 다른 문서”. 입력·출력이 바뀌어도 **AI 빌더로 정형 산출물을 만든다**는 패턴은 똑같습니다.

## AI 빌더 프롬프트 4가지 유형 (이번까지 정리)

| 유형 | 입력 | 출력 | 사용 모듈 |
|:-----|:-----|:-----|:---------|
| 텍스트 | 텍스트 | 텍스트 | M14, S8 |
| 멀티모달 | 텍스트 + **이미지** | 텍스트 | **S2** |
| 텍스트 (파일 입력) | **파일** | 텍스트 | **S3 (이번)** |
| **Word 아웃풋** | 텍스트 | **.docx 파일** | **S3 (이번)** |

## 산출물 체크리스트

| 항목 | 내용 |
|:-----|:-----|
| AI 빌더 프롬프트 | `DocExtractor` (입력=파일, 출력=정형 텍스트) |
| Word 템플릿 | `보고서_템플릿.docx` (제목 · 요약 · 표 자리표시자) |
| AI 빌더 Word 아웃풋 | 템플릿에 추출 결과 매핑 |
| Power Automate 흐름 | 에이전트 트리거 → AI 추출 → Word 출력 |

## 활용 시나리오

| 시나리오 | PDF 입력 | Word 출력 |
|:---------|:---------|:----------|
| 제안서 검토 | 제안서 원문 | 핵심 요약 보고서 |
