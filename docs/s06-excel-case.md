## Excel을 만나는 8가지 길

```
                          지식으로 쓰기 (매트릭스 ① 칸 — "굳이 쓰면" 영역)
                          ┌─────────────────────────────────────┐
                          │   ⓪          ①         ②         ③    │
                          │ 파일 첨부   직접 업로드  SP 파일    SP 폴더 │
                          │ (즉석)     (고정)      (자동 갱신)  (자동 갱신)│
                          └─────────────────────────────────────┘
              ⇩ 정밀 조회·갱신성·쓰기 필요해지면 ⇩
                          도구로 조회 (매트릭스 ② 칸 — "자연스러운" 영역)
                          ┌─────────────────────────────────────────┐
                          │   ④                ⑤              ⑥             │
                          │ Excel 커넥터    CSV + AI       Office Script   │
                          │ (단순 조건)     (AI 분석)       (정밀 쿼리)        │
                          └─────────────────────────────────────────┘
              ⇩ 데이터가 더 커지거나 공유 필요해지면 ⇩
                          구조 바꾸기 (Excel 졸업)
                          ┌─────────────────────────────┐
                          │   ⑦                ⑧         │
                          │ SP 리스트           Dataverse  │
                          └─────────────────────────────┘
```

## 강사 가이드 — 한 데이터셋, 한 질문

두 실습 모두 **같은 Excel과 같은 질문**으로 진행하면 비교가 가장 선명해집니다.

| 항목 | 권장 |
|:-----|:-----|
| 데이터 | 사내 자산 대장 Excel (~수백 행, 6~8 열) |
| 컬럼 | Env, OSType, Location, OwnerName, UsingDep 등 |
| 공통 질문 | "운영(LIVE) 환경 Linux 서버 목록 알려줘" |

같은 질문에 ⓪ → ⑥까지 차례로 실행해 **응답 품질·속도·정확도**를 비교합니다.
