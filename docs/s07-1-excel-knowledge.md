## 이 실습의 목표

- 같은 Excel을 **지식(Knowledge)** 으로 활용하는 **4가지 길**을 비교
- 각 방식의 한계를 눈으로 확인 — 왜 정밀 조회는 “도구 칸(실습 ②)”으로 가야 하는지 체감

{: .highlight }
> S6 매트릭스의 "정형 × 지식 (①)" 칸을 Excel로 구체화합니다. 사용 가능하지만 정밀 조회는 약하다는 것을 직접 봅니다.

## 전체 맵: Excel을 에이전트에 연결하는 8가지 방법

```
에이전트가 Excel을 만나는 8가지 길

         지식으로 쓰기 (AI가 읽고 해석)          ← S5
         ┌─────────────────────────────┐
    ⓪   │  ①         ②         ③     │
  파일첨부│ 직접 업로드  SP 파일    SP 폴더  │
  (즉석) │ (고정)     (자동갱신)  (자동갱신)│
         └─────────────────────────────┘

         도구로 조회 (흐름이 데이터를 가져옴)     ← S6
         ┌─────────────────────────────────────┐
         │  ④           ⑤          ⑥          │
         │ Excel 커넥터  CSV+AI    Office Script│
         │ (행 나열)    (AI 분석)   (정밀 쿼리)  │
         └─────────────────────────────────────┘

         구조를 바꾸기 (Excel 졸업)              ← S6 소개
         ┌─────────────────────────────┐
         │  ⑦           ⑧             │
         │ SP 리스트     Dataverse     │
         │ (리스트 DB)  (엔터프라이즈)   │
         └─────────────────────────────┘
```

이 모듈(S5)에서는 **윗줄 — 지식 방식 4가지**를 비교합니다.

## ⓪ 대화 중 파일 첨부

사전 설정 **없이**, 사용자가 대화 중 Excel 파일을 드래그&드롭합니다.

```
👤 "이 Excel 분석해줘" + 📎 파일 첨부
    ↓
🤖 AI가 파일 내용을 읽고 즉석 분석
```

| 항목 | 내용 |
|:-----|:-----|
| 설정 | 에이전트 설정에서 **파일 분석** 활성화만 하면 됨 |
| 장점 | **0분 설정**, 어떤 파일이든 즉석 분석 가능 |
| 단점 | 매번 파일을 올려야 함, 대용량 불가 |
| 적합한 상황 | 매번 **다른 파일**을 분석해야 할 때 |

---

## ① 지식에 직접 업로드

에이전트 빌더에서 **지식 → 파일 업로드**로 Excel을 등록합니다.

```
📊 Excel 파일
    ↓ (업로드)
🤖 에이전트 지식에 고정 등록
    ↓
👤 질문하면 AI가 지식에서 검색하여 답변
```

| 항목 | 내용 |
|:-----|:-----|
| 설정 | 에이전트 빌더 → 지식 → **파일 추가** |
| 장점 | 간단, 5분이면 완료 |
| 단점 | 파일이 바뀌면 **재업로드 필요**, 용량 제한 |
| 적합한 상황 | 거의 안 바뀌는 **참조용 데이터** |

{: .note }
> 기본과정 M7에서 이미 이 방식을 실습했습니다.

## ② SharePoint 파일 지식

SharePoint에 올린 Excel 파일을 **지식 소스**로 연결합니다.

```
📊 SharePoint의 Excel 파일
    ↓ (지식 소스 연결)
🤖 에이전트가 자동 인덱싱
    ↓
👤 질문하면 인덱싱된 내용에서 검색
```

| 항목 | 내용 |
|:-----|:-----|
| 설정 | 지식 → SharePoint → **파일 URL 지정** |
| 장점 | 파일 수정 시 **자동 재인덱싱** (주기적) |
| 단점 | 인덱싱 주기에 따라 지연, 의미 검색이라 정확도 한계 |
| 적합한 상황 | 주기적으로 업데이트되는 **문서성 데이터** |

---

## ③ SharePoint 폴더 지식

SharePoint 폴더 전체를 지식 소스로 등록합니다.

```
📁 SharePoint 폴더 (여러 파일)
    ↓ (폴더 단위 연결)
🤖 폴더 내 모든 파일 자동 인덱싱
    ↓
👤 질문하면 여러 파일에서 통합 검색
```

| 항목 | 내용 |
|:-----|:-----|
| 설정 | 지식 → SharePoint → **폴더 URL 지정** |
| 장점 | 파일 추가/삭제 자동 반영, **여러 파일 한 번에** |
| 단점 | ②와 동일한 인덱싱 지연, 검색 정확도 한계 |
| 적합한 상황 | 여러 Excel 파일을 **폴더로 관리**할 때 |

---

## 4가지 비교

| | ⓪ 파일 첨부 | ① 직접 업로드 | ② SP 파일 | ③ SP 폴더 |
|:--|:-----------|:-------------|:----------|:----------|
| 설정 시간 | 0분 | 5분 | 10분 | 10분 |
| 데이터 갱신 | 매번 첨부 | 재업로드 | 자동 (주기적) | 자동 (주기적) |
| 여러 파일 | ✗ | 개별 추가 | 개별 추가 | **폴더 단위** |
| 검색 방식 | AI 직접 읽기 | 의미 검색 | 의미 검색 | 의미 검색 |
| 정확도 | 중 | 중 | 중 | 중 |
| 대용량 | ✗ | ✗ | △ | △ |

{: .warning }
> **지식 방식의 공통 한계**: AI가 "의미 검색"으로 답하기 때문에, **"정확히 3번 행의 값"**처럼 구체적인 조회에는 약합니다. 정확한 조회가 필요하면 → 실습 ②(도구 3가지)에서 배웁니다.

## 시연: 같은 질문, 다른 결과

강사가 동일한 Excel 데이터와 동일한 질문으로 4가지 방식의 차이를 보여줍니다.

**질문**: "운영 환경 Linux 서버 목록 알려줘"

| 방식 | 예상 결과 |
|:-----|:---------|
| ⓪ 파일 첨부 | 파일 내용을 직접 읽어 답변 (정확도 높지만 매번 첨부 필요) |
| ① 직접 업로드 | "Linux 서버가 몇 대 있으며..." (의미 기반, 누락 가능) |
| ② SP 파일 | ①과 유사하나 최신 파일 자동 반영 |
| ③ SP 폴더 | 여러 파일에서 통합 검색 |

## 언제 어떤 방식을 쓸까?

```
Excel 데이터가 있다
    │
    ├─ 매번 다른 파일? ──── YES ──→ ⓪ 파일 첨부
    │
    ├─ 거의 안 바뀜? ───── YES ──→ ① 직접 업로드
    │
    ├─ 주기적으로 바뀜?
    │   ├─ 파일 1개? ──────────→ ② SP 파일
    │   └─ 파일 여러 개? ──────→ ③ SP 폴더
    │
    └─ 정확한 필터/조회 필요? ──→ 🔧 도구 방식 (S6)
```

{: .highlight }
> SharePoint 파일/폴더 비교는 이 모듈의 ②·③에서 Excel 맥락으로 함께 정리합니다. 다음 [실습 ②](s07-2-excel-tools)에서는 **도구로 정밀 조회하는 3가지 방법**을 배웁니다.
