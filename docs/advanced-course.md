## 기본과정 vs 심화과정

| | 기본과정 | 심화과정 |
|:--|:--------|:--------|
| 도구 종류 | 기본 커넥터 · 흐름 | **AI 빌더 · 커스텀 커넥터 · MCP** (S2~S5) |
| 파일 활용 | 지식 업로드 | **지식 / 대화 업로드 / AI 빌더 — 3가지 길** (S1) |
| 데이터 사고 | 단일 사례 | **정형/비정형 × 지식/도구 매트릭스** (S6·S7) |
| 입력 UI | 텍스트 대화 | **엔티티 + AI 프롬프트 + 어댑티브 카드** (S8) |
| 설계 | — | **토픽/플로우 vs 지침 중심 + 도구 선택 트리** (S9) |
| 운영 | — | **솔루션 · 환경 변수 · dev↔prod 분리** (S10) |
