## 완성 흐름 구조

| 항목 | 내용 |
|:-----|:-----|
| **흐름 이름** | HR_Request |
| **트리거** | 에이전트가 흐름을 호출할 때 |
| **입력 ①** | `mySender` (텍스트): 문의자 이름 |
| **입력 ②** | `myRequest` (텍스트): 문의 내용 |
| **동작** | Microsoft Teams — 채팅 또는 채널에서 메시지 게시 |
| **출력** | `myResult`: 문의완료 |

---

## Step 1 — 새 에이전트 흐름 만들기

1. Copilot Studio 좌측 메뉴에서 **"흐름"** 클릭
2. **"+ 새 에이전트 흐름"** 클릭

   ![에이전트 흐름 목록 — 새 에이전트 흐름 클릭](../assets/images/m13-1/image1.png)

---

## Step 2 — 트리거 설정

1. 트리거 추가 화면에서 **"에이전트"** 검색
2. **"에이전트가 흐름을 호출할 때"** 선택

   ![트리거 추가 — 에이전트 검색 후 에이전트가 흐름을 호출할 때 선택](../assets/images/m13-1/image2.png)

---

## Step 3 — 입력 변수 2개 추가

1. 트리거 카드에서 **"+ 입력 추가"** 클릭

   ![에이전트가 흐름을 호출할 때 — 입력 추가 클릭](../assets/images/m13-1/image3.png)

2. 사용자 입력 유형에서 **"텍스트"** 선택

   ![사용자 입력 유형 선택 — 텍스트](../assets/images/m13-1/image4.png)

3. 입력 이름을 **`mySender`**로 입력하고, 같은 방법으로 두 번째 입력도 추가

   ![mySender 입력 후 두 번째 텍스트 입력 추가](../assets/images/m13-1/image5.png)

4. **2개 입력 변수** 완성 확인:

   | 입력 이름 | 유형 | 설명 |
   |:---------|:-----|:-----|
   | `mySender` | 텍스트 | 문의자 이름 |
   | `myRequest` | 텍스트 | 문의 내용 |

   ![입력 변수 2개 완성 — mySender, myRequest](../assets/images/m13-1/image6.png)

---

## Step 4 — 출력 노드 설정 (에이전트에게 응답)

트리거 아래 **⊕** 버튼을 클릭하여 출력 노드를 먼저 추가합니다.

1. **⊕** 버튼 → 작업 추가 → AI 기능 → **"에이전트에게 응답"** 선택

   ![작업 추가 — 에이전트에게 응답 선택](../assets/images/m13-1/image7.png)

2. **"+ 출력 추가"** → 텍스트 유형으로 출력 변수 추가:
   - **이름**: `myResult`
   - **값**: `문의완료`

   ![에이전트에게 응답 — myResult 출력 변수 추가](../assets/images/m13-1/image8.png)

---

## Step 5 — Teams 메시지 게시 동작 추가

트리거와 응답 **사이에** Teams 메시지 게시 동작을 넣습니다.

1. 트리거와 응답 사이의 **⊕ 버튼** 클릭

   ![트리거와 에이전트에게 응답 사이 ⊕ 버튼 클릭](../assets/images/m13-1/image9.png)

2. 작업 추가 → **"teams"** 검색 → **Microsoft Teams** 선택

   ![작업 추가 — teams 검색 후 Microsoft Teams 선택](../assets/images/m13-1/image10.png)

3. Microsoft Teams 동작 목록에서 **"채팅 또는 채널에서 메시지 게시"** 선택

   ![Microsoft Teams — 채팅 또는 채널에서 메시지 게시 선택](../assets/images/m13-1/image11.png)

---

### 5-1. 메시지 게시 카드 설정

1. **채팅 또는 채널에서 메시지 게시** 카드가 추가됨

   ![채팅 또는 채널에서 메시지 게시 카드 — 기본 설정](../assets/images/m13-1/image12.png)

   경우에 따라 "흐름 봇" 대신, "사용자"를 선택해야 할 수도 있습니다. 이 경우 드롭다운에서 **"사용자"** 선택

   ![채팅 또는 채널에서 메시지 게시 카드 — 기본 설정](../assets/images/m13-1/image12a.png)


2. **게시 위치** 드롭다운 → **"채널"** 선택

   ![게시 위치 — 채널 선택](../assets/images/m13-1/image13.png)

3. **팀** 드롭다운 → 본인 팀 선택 (예: `t1`)

   ![팀 선택 — t1](../assets/images/m13-1/image14.png)

4. **채널** 드롭다운 → 메시지를 수신할 채널 선택 (예: `문의 수신 채널`)

   ![채널 선택 — 문의 수신 채널](../assets/images/m13-1/image15.png)

---

### 5-2. 메시지 본문 작성

1. **메시지** 영역에 아래와 같이 직접 입력:

   ```
   시각 :
   문의자 :
   문의내용 :
   ```

   ![메시지 본문 — 시각, 문의자, 문의내용 텍스트 입력](../assets/images/m13-1/image16.png)

2. **시각** 뒤에 커서를 놓고 우측 **fx** 아이콘 클릭 → `utcNow()` 입력 → **"추가"** 클릭

   ![fx 패널 — utcNow() 입력 후 추가 클릭](../assets/images/m13-1/image16a.png)

3. **문의자** 뒤에 커서를 놓고 **번개(⚡)** 아이콘 → 동적 콘텐츠에서 **`mySender`** 선택

   ![시각에 utcNow() 삽입, 문의자에 번개 아이콘으로 동적 콘텐츠 매핑](../assets/images/m13-1/image17.png)

4. **문의내용** 뒤에 동적 콘텐츠 **`myRequest`** 선택 → 완성 후 **"초안 저장"** 클릭

   | 필드 | 값 |
   |:-----|:---|
   | **시각** | `utcNow()` (함수) |
   | **문의자** | `mySender` (동적 콘텐츠) |
   | **문의내용** | `myRequest` (동적 콘텐츠) |

   ![메시지 완성 — utcNow(), mySender, myRequest 매핑 후 초안 저장](../assets/images/m13-1/image18.png)

---

## Step 6 — 흐름 테스트

1. 전체 흐름 확인: **에이전트가 흐름을 호출할 때** → **채팅 또는 채널에서 메시지 게시** → **에이전트에게 응답**
2. 상단 **"테스트"** 클릭

   ![HR_Request 전체 흐름 — 테스트 클릭](../assets/images/m13-1/image19.png)

3. **"수동"** 선택 → **"테스트"** 클릭

   ![흐름 테스트 — 수동 선택 후 테스트 클릭](../assets/images/m13-1/image20.png)

4. 입력값 입력:

   | 입력 | 테스트 값 |
   |:-----|:---------|
   | **mySender** | `갑돌이` |
   | **myRequest** | `휴가를 더 늘려줘요` |

   → **"흐름 실행"** 클릭

   ![테스트 입력값 — mySender: 갑돌이, myRequest: 휴가를 더 늘려줘요 → 흐름 실행](../assets/images/m13-1/image21.png)

5. **"흐름 실행이 시작되었습니다"** ✅ → **"완료"** 클릭

   ![흐름 실행 성공 — 완료 클릭](../assets/images/m13-1/image22.png)

6. **Teams** → 선택한 채널에서 메시지 수신 확인 🎉

   ![Teams 문의 수신 채널 — 시각, 문의자: 갑돌이, 문의내용: 휴가를 더 늘려줘요 확인](../assets/images/m13-1/image23.png)

---

## Step 7 — 흐름 이름 변경

1. 상단 **"개요"** 탭 → 세부 정보 **"편집"** 클릭
2. **흐름 이름**: `HR_Request` 로 변경
3. **"저장"** 클릭

   ![개요 탭 — 흐름 이름 HR_Request로 변경 후 저장](../assets/images/m13-1/image24.png)

---

## Step 8 — 연결 참조 관리

흐름을 에이전트에서 호출할 때 Teams 연결이 필요합니다. 연결 참조를 설정합니다.

1. **개요** 탭 → 연결 참조 영역에서 **"관리"** 클릭

   ![개요 페이지 — 연결 참조 관리 클릭](../assets/images/m13-1/image25.png)

2. Microsoft Teams 연결 → **"실행 전용 사용자가 제공함"** 드롭다운 → 본인 계정 선택

   ![연결 참조 관리 — 실행 전용 사용자가 제공함 → 본인 계정 선택](../assets/images/m13-1/image26.png)

3. 연결 변경 확인 팝업 → **"확인"** 클릭

   ![연결 변경 확인 팝업 — 확인 클릭](../assets/images/m13-1/image27.png)

4. 연결 설정 완료 → **"저장"** 클릭

   ![연결 참조 관리 완료 — 저장 클릭](../assets/images/m13-1/image28.png)

{: .tip }
> 연결 참조를 **"실행 전용 사용자가 제공함"**으로 설정하면, 에이전트에서 흐름을 호출할 때 **본인 계정의 Teams 권한**으로 메시지가 게시됩니다.

---

## Step 9 — 게시

1. **"디자이너"** 탭으로 이동 → 우측 상단 **"게시"** 클릭

   ![디자이너 탭 — 게시 클릭](../assets/images/m13-1/image29.png)

{: .warning }
> **게시하지 않으면** Copilot Studio에서 이 흐름을 도구로 추가할 수 없습니다. 반드시 게시를 완료하세요.

---

{: .highlight }
> 흐름 만들기가 완료되면 실습 ②에서 이 흐름을 **도구로 추가**하고, **지침(STRICT RULES)**으로 호출 규칙을 작성합니다.
