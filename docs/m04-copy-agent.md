## 에이전트 빌더 vs Copilot Studio

M3에서 만든 에이전트 빌더도 충분히 강력합니다.  
하지만 오늘 과정에서 다룰 고급 기능은 **Copilot Studio(풀 버전)**에서만 가능합니다.

### 지식 소스 비교

| 지식 소스 | 에이전트 빌더 | Copilot Studio |
|:---------|:----------:|:------------:|
| 웹사이트 URL | ✅ | ✅ |
| SharePoint | ✅ | ✅ |
| 파일 직접 업로드 (Word, PDF 등) | ✅ | ✅ |
| Dataverse 테이블 | ❌ | ✅ |
| AI Search 인덱스 | ❌ | ✅ |
| Azure OpenAI 커스텀 지식 | ❌ | ✅ |

### 도구 비교

| 도구 유형 | 에이전트 빌더 | Copilot Studio |
|:---------|:----------:|:------------:|
| 이미지 생성 / 코드 인터프리터 | ✅ | ✅ |
| **토픽(대본형 대화 흐름)** | ❌ | ✅ |
| **커넥터 (1,400+ 외부 서비스)** | ❌ | ✅ |
| **에이전트 흐름 (Power Automate)** | ❌ | ✅ |
| **AI 프롬프트 / 멀티에이전트 / MCP / 트리거** | ❌ | ✅ |

![에이전트 빌더 vs Copilot Studio — 지식과 도구의 범위 비교](../assets/images/m03/builder-vs-studio.png)

{: .highlight }
> **에이전트 빌더 = 충분히 강력한 기본기.**  
> **Copilot Studio = 더 넓은 지식과 더 많은 도구.**  
> 오늘 과정에서는 Studio의 고급 기능을 배우기 위해 복사합니다.

### 언제 어떤 것을 선택하는가?

| 요건 | 에이전트 빌더로 충분 | Copilot Studio 필요 |
|:-----|:-----------------:|:-----------------:|
| 웹사이트/SharePoint FAQ 봇 | ✅ | |
| 이미지 생성 · 데이터 분석 | ✅ | |
| **토픽 · 커넥터 · 흐름 · 멀티에이전트** | | ✅ |
| **레거시 API 연동 · AI Search** | | ✅ |

{: .tip }
> 실무에서는 에이전트 빌더만으로 해결되는 경우도 많습니다. **"가장 단순한 도구로 충분히 되는지"를 먼저 판단**하는 것이 좋습니다.

---

## 왜 복사하나요?

같은 에이전트인데, **편집 도구만 바뀌는 것**입니다.  
스마트폰 카메라(에이전트 빌더)로 찍은 사진을 포토샵(Copilot Studio)에서 보정하는 것과 같습니다.

---

## 실습 ①: 솔루션 만들기

에이전트를 독립된 솔루션에 넣으면 나중에 내보내기(Export)나 이동이 편리합니다.  
실습 ②에서 에이전트를 가져오기 전에, **솔루션을 먼저 준비**해 둡니다.

{: .important }
> 📌 이 실습은 별도 페이지에서 진행합니다.  
> [실습 ①: 솔루션 만들기](m04-1-open-in-studio)를 완료하고 돌아오세요.

---

## 실습 ②: Copilot Studio로 가져오기

에이전트 빌더에서 만든 에이전트를 Copilot Studio로 복사한 뒤, **언어를 한국어로**, **솔루션을 실습 ①에서 만든 솔루션으로** 설정합니다.

{: .important }
> 📌 이 실습은 별도 페이지에서 진행합니다.  
> [실습 ②: Copilot Studio로 가져오기](m04-2-studio-new-agent)를 완료하고 돌아오세요.

## 핵심 정리

1. 에이전트 빌더는 강력하지만, **토픽·커넥터·흐름** 등 고급 기능은 Copilot Studio에서만 가능
2. 에이전트 빌더로 만든 에이전트를 **Copilot Studio로 복사**하면 고급 기능 사용 가능
3. 솔루션을 먼저 만들고, 복사 시 **한국어 + 솔루션**을 설정
4. **이후 실습은 실습 ②에서 만든 에이전트**를 계속 사용하며 지침·지식·Topic·Flow를 붙여 완성한다

## FAQ

| 질문 | 답변 |
|:-----|:-----|
| 에이전트 빌더만으로 충분한 경우도 있나요? | **네.** 웹/SharePoint 지식 + 이미지 생성 + 코드 인터프리터면 충분한 경우가 많습니다. |
| 그럼 왜 Copilot Studio를 배우나요? | 대화 흐름 제어, 외부 서비스 연동, 자동화 등 **범위를 넘는 요건**이 있을 때 필요하기 때문입니다. |
| 솔루션을 꼭 만들어야 하나요? | 필수는 아니지만, 솔루션 안에 만들면 내보내기/이동이 편리합니다. |
