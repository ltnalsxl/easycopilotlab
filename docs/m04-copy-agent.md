## 이 모듈에서 배우는 것

- 에이전트 빌더에서 만든 에이전트를 **Copilot Studio로 복사**하는 방법
- 복사 전에 **솔루션을 먼저 준비**하는 이유
- 복사된 에이전트에서 **언어와 솔루션을 설정**하는 방법

{: .highlight }
> M3에서 에이전트 빌더로 만든 HR 도우미는 훌륭하지만, 고급 기능(토픽, 커넥터, 흐름 등)을 사용하려면 **Copilot Studio(풀 버전)**로 옮겨야 합니다. 이 모듈에서 복사를 완료하면, 이후 실습은 모두 Copilot Studio에서 진행합니다.

---

## 왜 복사하나요?

에이전트 빌더(Copilot Studio 라이트)에서 만든 에이전트를 **Copilot Studio 풀 버전**으로 가져오면:

| 구분 | 에이전트 빌더 | Copilot Studio |
|:-----|:----------:|:------------:|
| 토픽(대본형 대화 흐름) | ❌ | ✅ |
| 커넥터 (1,400+ 외부 서비스) | ❌ | ✅ |
| 에이전트 흐름 (Power Automate) | ❌ | ✅ |
| 멀티에이전트 | ❌ | ✅ |

{: .tip }
> 같은 에이전트인데, **편집 도구만 바뀌었습니다.** 스마트폰 카메라(에이전트 빌더)로 찍은 사진을 포토샵(Copilot Studio)에서 보정하는 것과 같습니다.

---

## 실습 ①: 솔루션 만들기

에이전트를 독립된 솔루션에 넣으면 나중에 내보내기(Export)나 이동이 편리합니다.  
실습 ②에서 에이전트를 가져오기 전에, **솔루션을 먼저 준비**해 둡니다.

{: .important }
> 📌 이 실습은 별도 페이지에서 진행합니다.  
> [실습 ①: 솔루션 만들기](m04-1-open-in-studio)를 완료하고 돌아오세요.

---

## 실습 ②: Copilot Studio로 가져오기

에이전트 빌더에서 만든 에이전트를 Copilot Studio로 복사한 뒤, **언어를 한국어로**, **솔루션을 실습 ①에서 만든 솔루션으로** 설정합니다.

{: .important }
> 📌 이 실습은 별도 페이지에서 진행합니다.  
> [실습 ②: Copilot Studio로 가져오기](m04-2-studio-new-agent)를 완료하고 돌아오세요.

---

## 핵심 정리

1. 에이전트 빌더로 만든 에이전트를 **Copilot Studio로 복사**하면 고급 기능 사용 가능
2. 솔루션을 먼저 만들고, 복사 시 **한국어 + 솔루션**을 설정
3. **이후 실습은 실습 ②에서 만든 에이전트**를 계속 사용하며 지침·지식·Topic·Flow를 붙여 완성한다
