## 이 모듈에서 배우는 것

- 기본과정(M16)의 Forms 트리거를 넘어 **다양한 이벤트 소스** 활용
- **Outlook 메일 수신 트리거** — 특정 키워드 메일 도착 시 자동 처리
- **스케줄 트리거** — 정해진 시간에 에이전트가 스스로 작동
- 트리거 선택 기준 이해

---

## 기본과정에서는

기본과정 M16에서 **Forms 제출 → 에이전트 자동 실행**을 배웠습니다.

```
📝 Forms 제출 → ⚡ 트리거 → 🤖 AI 초안 생성 → 📧 담당자 메일
```

심화과정에서는 **Forms 외의 이벤트 소스**로 확장합니다.

---

## 트리거 유형 비교

| 트리거 | 이벤트 소스 | 예시 |
|:-------|:-----------|:-----|
| Forms 트리거 (기본) | 설문 제출 | HR 문의 접수 |
| **메일 트리거** (심화) | Outlook 메일 수신 | 고객 문의 메일 자동 분류 |
| **스케줄 트리거** (심화) | 시간/날짜 도래 | 매주 월요일 주간 보고 생성 |

---

## 시나리오 ①: 메일 트리거

> 특정 키워드가 포함된 메일이 도착하면, 에이전트가 내용을 요약하고 Teams에 알림을 보냅니다.

```
📧 메일 수신 (제목에 "문의" 포함)
    ↓
⚡ 트리거 발동
    ↓
🤖 에이전트: 메일 본문 요약 + 긴급도 판단
    ↓
💬 Teams 채널에 요약 알림 게시
```

### 핵심 설정

| 설정 | 값 |
|:-----|:---|
| 트리거 조건 | 메일 제목에 특정 키워드 포함 |
| AI 처리 | 본문 요약 + 긴급도 분류 (높음/보통/낮음) |
| 출력 | Teams 채널 메시지 |

---

## 시나리오 ②: 스케줄 트리거

> 매주 월요일 오전 9시, 에이전트가 지난주 대화 기록을 요약해서 Teams에 게시합니다.

```
⏰ 매주 월요일 09:00
    ↓
⚡ 스케줄 트리거 발동
    ↓
🤖 에이전트: 지난주 대화 로그 분석 + 주간 요약 생성
    ↓
💬 Teams 채널에 주간 보고 게시
```

{: .note }
> 스케줄 트리거는 **자율 에이전트(Autonomous Agent)**의 시작점입니다. 사람이 아무것도 하지 않아도 에이전트가 알아서 작동합니다.

---

## 트리거 선택 가이드

| 상황 | 추천 트리거 |
|:-----|:-----------|
| 사용자가 양식을 작성할 때 | Forms 트리거 |
| 외부에서 메일이 올 때 | **메일 트리거** |
| 정기적으로 반복되는 작업 | **스케줄 트리거** |
| 특정 파일이 업로드될 때 | SharePoint 트리거 |
| Teams 메시지가 올 때 | Teams 트리거 |

---

## 기본과정 vs 심화과정 트리거

| | 기본과정 (M16) | 심화과정 (S2) |
|:--|:--------------|:-------------|
| 이벤트 소스 | Forms | 메일, 스케줄 |
| 패턴 | 휴먼인더루프 | 휴먼인더루프 + **자율 실행** |
| AI 처리 | 답변 초안 생성 | 요약 + 분류 + 알림 |
| 출력 | 메일 | Teams 채널 |
