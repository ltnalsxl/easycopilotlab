## 이 모듈에서 배우는 것

- **엔티티(Entity)** — 사용자 발화에서 날짜·숫자·항목을 **자동으로 인식**하는 방법
- **커스텀 엔티티** — 부서명, 경비 유형 등 **우리 팀만의 항목** 정의
- **어댑티브 카드(Adaptive Card)** — 텍스트 대신 **카드 UI**로 입출력
- 엔티티로 추출 → 카드로 확인 → 최종 저장 **흐름 구현**

---

## 기본과정에서는

기본과정 M9에서 **변수 = 포스트잇** 개념을 배웠습니다.  
변수는 사용자가 **직접 입력한 값**을 저장합니다.

```
사용자: "홍길동 연락처 알려줘"
     ↓
변수에 "홍길동" 저장 (사용자가 직접 말한 값)
```

---

## 엔티티 = 밑줄 치기

엔티티는 사용자의 **자연어 발화에서 정보를 알아서 뽑아내는** 기능입니다.

```
사용자: "다음 주 화요일 서울 출장 교통비 5만원 처리해주세요"
     ↓
🔍 엔티티 자동 추출:
   📅 날짜: 다음 주 화요일
   📍 장소: 서울
   💰 금액: 50,000원
   📂 유형: 교통비
```

| | 변수 (기본) | 엔티티 (심화) |
|:--|:-----------|:-------------|
| 비유 | 빈칸 채우기 | **밑줄 치기** |
| 입력 방식 | 사용자에게 하나씩 질문 | 한 문장에서 **자동 추출** |
| 사용자 경험 | "날짜를 입력하세요" | "다음 주 화요일 출장" → 자동 인식 |

## 내장 엔티티 vs 커스텀 엔티티

### 내장 엔티티

Copilot Studio가 기본 제공하는 엔티티입니다.

| 엔티티 | 인식 예시 |
|:-------|:---------|
| 날짜/시간 | "다음 주 화요일", "3월 15일" |
| 숫자 | "5만원", "3개" |
| 이메일 | "hong@company.com" |
| 전화번호 | "010-1234-5678" |

### 커스텀 엔티티

우리 팀의 업무에 맞는 **나만의 엔티티**를 만듭니다.

| 커스텀 엔티티 | 항목 예시 |
|:-------------|:---------|
| 경비 유형 | 교통비, 숙박비, 식비, 기타 |
| 부서명 | 인사팀, 총무팀, 개발팀, 영업팀 |
| 문의 유형 | 연차, 경비, 복지, 증명서 |

## 실습 ①: 엔티티로 자동 추출

### 내장 엔티티 체험

> "다음 주 화요일 서울 출장 교통비 5만원"  
> → 날짜, 금액을 자동으로 인식하는지 확인

### 커스텀 엔티티 만들기

> 경비 유형 엔티티 생성: 교통비 / 숙박비 / 식비 / 기타  
> → "식비 3만원 처리해줘"에서 유형을 자동으로 인식하는지 확인

## 어댑티브 카드 = 카드 양식

어댑티브 카드는 텍스트 대화 대신 **시각적 카드 UI**를 보여주는 기능입니다.

### 텍스트 대화 vs 카드 UI

| 텍스트 대화 (기본) | 카드 UI (심화) |
|:------------------|:-------------|
| 봇: "날짜를 입력하세요" | 카드에 날짜 선택기 표시 |
| 사용자: "3월 15일" | 사용자: 캘린더에서 클릭 |
| 봇: "유형을 선택하세요" | 카드에 드롭다운 표시 |
| 사용자: "교통비" | 사용자: 목록에서 선택 |

{: .highlight }
> 여러 번 주고받을 대화를 **카드 한 장으로** 끝낼 수 있습니다.

---

## 어댑티브 카드 만들기

### 카드 디자이너

[Adaptive Cards Designer](https://adaptivecards.io/designer/)에서 시각적으로 카드를 디자인하고 JSON을 생성합니다.

### 카드 구성 요소

| 요소 | 용도 | 예시 |
|:-----|:-----|:-----|
| TextBlock | 안내 문구 | "경비 신청 정보를 입력하세요" |
| Input.Date | 날짜 선택 | 출장 날짜 |
| Input.ChoiceSet | 드롭다운 선택 | 경비 유형 (교통/숙박/식비) |
| Input.Number | 숫자 입력 | 금액 |
| Input.Text | 텍스트 입력 | 비고 |
| Action.Submit | 제출 버튼 | "신청하기" |

## 실습 ②: 어댑티브 카드로 확인

### 흐름

```
① 사용자: "다음 주 화요일 서울 출장 교통비 5만원"
     ↓
② 엔티티: 날짜·금액·유형 자동 추출
     ↓
③ 어댑티브 카드: 추출된 값을 채워서 확인 카드 표시
   ┌─────────────────────────┐
   │  📋 경비 신청 확인       │
   │  날짜: 4월 8일 (화)     │
   │  장소: 서울             │
   │  유형: [교통비 ▼]       │
   │  금액: 50,000           │
   │  비고: [              ] │
   │         [신청하기]      │
   └─────────────────────────┘
     ↓
④ 사용자: 확인/수정 후 "신청하기" 클릭
     ↓
⑤ 변수에 최종 값 저장
```

{: .tip }
> **엔티티가 뽑고, 카드가 확인받고, 변수가 저장한다** — 이 3단계가 사용자 입력 처리의 완성형입니다.

## 언제 엔티티, 언제 카드?

| 상황 | 추천 |
|:-----|:-----|
| 간단한 정보 1~2개 | 엔티티만으로 충분 |
| 여러 항목을 한 번에 입력 | **어댑티브 카드** |
| AI가 추출한 값을 확인받아야 할 때 | **엔티티 + 카드 조합** |
| 모바일 사용자가 많을 때 | **어댑티브 카드** (터치 친화적) |
