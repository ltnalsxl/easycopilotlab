## 기본과정 → 심화과정 성장 맵

```
기본과정                          심화과정
────────────────                ──────────────────
—                    →→→         파일 다루기 3길 정리 (S1)
파일 업로드          →→→         Excel × 지식 4가지 비교 (S7)
Excel 커넥터         →→→         Excel × 도구 3가지 + 졸업 옵션 (S7)
AI 프롬프트 (소개)    →→→         AI Builder 멀티모달·Word·파일입력 (S2·S3)
기본 커넥터          →→→         커스텀 커넥터(S4) + MCP(S5)
변수(포스트잇)        →→→         엔티티·어댑티브 카드 (S8)
—                    →→→         도구 결정 트리·패턴 정리 (S9)
—                    →→→         솔루션 + 환경 변수 (S10)
```

## 오늘 배운 핵심 개념 정리

### AI Builder 프롬프트 유형

| 유형 | 입력 | 출력 | 모듈 |
|:-----|:-----|:-----|:-----|
| 텍스트 | 텍스트 | 텍스트 | S8 |
| 멀티모달 | 텍스트 + 이미지 | 텍스트(JSON) | S2 |
| 파일 입력 | 파일 + 텍스트 | 텍스트(JSON) | S3 |
| Word 아웃풋 | 텍스트 | .docx | S3 |

### 입력 처리 방식

| 방식 | 특징 | 모듈 |
|:-----|:-----|:-----|
| 변수 (기본) | 사용자에게 하나씩 질문 | M10 |
| 엔티티 (심화) | 발화에서 자동 추출 | S8 |
| 어댑티브 카드 (심화) | 카드 UI로 한 번에 입력 | S8 |

### 외부 연결 방식

| 방식 | 범위 | 모듈 |
|:-----|:-----|:-----|
| 기본 커넥터 | Microsoft 365 + 인기 서비스 | M12 |
| 커스텀 커넥터 | 모든 REST API | S4 |
| MCP | 표준 프로토콜 서버 | S5 |

### 데이터를 다루는 자리

| 데이터 모양 | 답변만 필요 | 산출물·정밀 조회 필요 |
|:-----------|:------------|:--------------------|
| 비정형 (PDF·이미지) | 지식 (M8 / S1 ①·②) | AI Builder (S2·S3) |
| 정형 (Excel·SP) | 지식 △ (S7 ①) | 도구 ◎ (S7 ②) |

## 다음 단계 — 이제 뭘 할 수 있을까?

| 단계 | 설명 |
|:-----|:-----|
| **복제·확장** | 오늘 만든 패턴으로 **다른 업무 시나리오** 적용 |
| **솔루션 정리** | 흩어진 흐름·에이전트를 솔루션 안으로 **묶기** |
| **환경 분리** | dev에서 만든 솔루션을 **test/prod**로 이동 시도 |
| **팀 배포** | 만든 에이전트를 팀에 공유하고 **피드백 수집** |
| **자율 에이전트** | 스케줄 트리거로 **사람 개입 없는 자동화** 확대 |
