## 기본과정 → 심화과정 성장 맵

```
기본과정                          심화과정
────────────────                ──────────────────
—                    →→→         에이전트 설계 전략
파일 업로드          →→→         Excel × 지식 4가지 비교
—                    →→→         SP 파일/폴더 실습
변수 (포스트잇)       →→→         엔티티 (자동 추출)
텍스트 대화          →→→         어댑티브 카드 UI
—                    →→→         환경 변수 (dev/prod)
Excel 커넥터         →→→         AI 멀티모달 + Scripts
—                    →→→         Excel × 도구 3가지 비교
AI 프롬프트 (소개)    →→→         Word 아웃풋 실전
기본 커넥터          →→→         MCP + 커스텀 커넥터
```
