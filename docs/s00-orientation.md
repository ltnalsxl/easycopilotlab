## 심화과정에서 다룰 것

기본과정의 4가지 구성요소를 **한 단계 더 깊이** 다룹니다.

| 모듈 | 제목 | 기본과정 대비 확장 |
|:-----|:-----|:-----------------|
| S1 | 에이전트 설계 전략 | — → **업무 분석 · 지식 · 도구 · 환경 변수 전략** |
| S2 | SP 파일 vs 폴더 | 파일 업로드 → **SharePoint 연결** |
| S3 | 트리거 심화 | Forms 트리거 → **메일/스케줄 트리거** |
| S4 | 엔티티 + 어댑티브 카드 | 텍스트 입력 → **자동 인식 + 카드 UI** |
| S5 | 환경 변수 | — → **설정값을 변수로 관리 (dev/prod)** |
| S6 | 영수증 → 엑셀 자동 저장 | Excel 커넥터 → **AI 멀티모달 + Scripts** |
| S7 | PDF → Word 보고서 | AI 프롬프트 소개 → **Word 아웃풋 실전** |
| S8 | MCP 서버 연결 | — → **MCP로 외부 서비스 도구 일괄 연결** |
| S9 | 커스텀 커넥터 | 기본 커넥터 → **외부 API 직접 등록** |

## 오늘의 결과물 미리보기

오늘 과정이 끝나면 아래를 모두 경험하게 됩니다.

| # | 결과물 |
|:--|:-------|

| 2 | SharePoint 라이브러리를 지식 소스로 연결한 에이전트 |
| 3 | 메일 수신 시 자동으로 작동하는 트리거 |

| 5 | 어댑티브 카드로 양식 입력을 받는 UI |
| 6 | 환경 변수로 URL을 관리하는 솔루션 |
| 7 | 영수증 사진 → AI 분석 → Excel 자동 저장 파이프라인 |
