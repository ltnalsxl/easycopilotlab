## 심화과정에서 다룰 것

기본과정에서는 에이전트를 만들고, 파일 지식을 넣고, 토픽·커넥터·흐름·트리거를 한 번씩 연결해보았습니다.

심화과정에서는 이 경험을 바탕으로 **지식 소스 선택, Excel 데이터 연결, AI Builder 자동화, 외부 도구 연결**을 실제 시나리오로 비교합니다.

| 모듈 | 실제로 다루는 내용 |
|:-----|:-------------------|
| S1 | 에이전트로 만들기 좋은 업무를 고르고, 지식 소스와 도구를 선택하는 기준을 정리합니다. |
| S2 | SharePoint의 **파일 단위 연결**과 **폴더/라이브러리 단위 연결**을 같은 질문으로 비교합니다. |
| S3 | 내장/커스텀 엔티티로 사용자 발화에서 값을 추출하고, 어댑티브 카드로 확인·수정받습니다. |
| S4 | `ExcelTableUrl`, `SharePointSiteUrl` 같은 값을 환경 변수로 만들어 흐름에서 참조합니다. |
| S5 | 영수증 이미지를 AI Builder 멀티모달 프롬프트로 분석하고, JSON과 Office Script로 Excel에 저장합니다. |
| S6 | Excel을 지식으로 쓰는 4가지 방법을 비교합니다: ⓪ 파일 첨부, ① 직접 업로드, ② SP 파일, ③ SP 폴더. |
| S7 | Excel을 도구로 조회하는 3가지 방법을 비교합니다: ④ Excel 커넥터, ⑤ CSV+AI 프롬프트, ⑥ Office Script. 이어서 ⑦ SharePoint 리스트, ⑧ Dataverse로 확장하는 기준도 봅니다. |
| S8 | PDF를 업로드받아 AI Builder 프롬프트로 정보를 추출하고, Word 템플릿 보고서로 출력합니다. |
| S9 | MCP 개념을 이해하고, Microsoft Learn MCP 서버를 에이전트 도구로 연결합니다. |
| S10 | 외부 환율 REST API를 OpenAPI 정의로 등록하고, 커스텀 커넥터를 에이전트에서 호출합니다. |
