## 심화과정에서 다룰 것

기본과정에서는 에이전트를 만들고, 파일 지식을 넣고, 토픽·커넥터·흐름·트리거를 한 번씩 연결해보았습니다.

심화과정에서는 이 경험을 바탕으로 **고급 도구 → 데이터 다루기 → 설계 패턴 → ALM**의 순서로 한 단계씩 확장합니다.

| 블록 | 모듈 | 한 줄로 |
|:--|:--|:--|
| **2. 고급 도구** | S1 파일 다루기 3가지 | 지식 / 대화 업로드 / AI 빌더 — 언제 어떤 길을 쓸지 |
| | S2 영수증 → Excel | 이미지 입력 + JSON + Office Script로 표에 행 추가 |
| | S3 PDF → Word | 파일 입력 + Word 템플릿으로 보고서 자동 생성 |
