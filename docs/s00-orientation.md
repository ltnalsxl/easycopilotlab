## 심화과정에서 다룰 것

기본과정에서는 에이전트를 만들고, 파일 지식을 넣고, 토픽·커넥터·흐름·트리거를 한 번씩 연결해보았습니다.

심화과정에서는 이 경험을 바탕으로 **오전 3세션으로 "오늘 만들 수 있는 것"을 한 번에 보여주고 → 오후에 외부 연결·데이터·UX·운영으로 폭을 넓히는** 순서로 한 단계씩 확장합니다.

| 블록 | 모듈 | 한 줄로 |
|:--|:--|:--|
| **1. 오전 집중** | S1 문서 업로드 활용 실습 | 회의록 PDF → 표준 Word — 빌트인에서 AI 빌더까지 4단계 그라디언트 |
| | S2 엑셀 업로드 활용 실습 | 질문 노드 + Table / 흐름 + 커넥터 + OData / 흐름 + Office Script |
| | S3 12 패턴 카탈로그 | 데이터 매트릭스 + 12 설계 패턴 + 결정 트리 |
| **2. 외부 연결** | S4 커스텀 커넥터 | OpenAPI 정의로 외부 REST API를 도구로 등록 |
| | S5 MCP | MCP 서버 하나로 여러 외부 도구를 한 번에 연결 |
| **3. 데이터·UX·운영** | S6 Excel 케이스 스터디 | 같은 Excel을 지식 4가지 + 도구 3가지로 다뤄보고 졸업 기준 정리 |
| | S7 입력 구조화 | 엔티티 + AI 프롬프트 + 어댑티브 카드 |
| | S8 ALM + 환경 변수 | 솔루션 · dev↔prod · 환경 변수로 운영 가능한 상태로 |
| | S9 마무리 | Q&A + 체크리스트 |
