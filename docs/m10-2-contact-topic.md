# 실습 ②: Contact Topic 만들기
{: .no_toc }

| 시간 | 소요 | 수강생 역할 |
|:-----|:-----|:-----------|
| 14:20 | 10분 | 🟢 직접 실습 |

---

| 항목 | 내용 |
|:-----|:-----|
| **Topic 이름** | Contact Topic |
| **역할** | 담당자 조회 요청 시 간단한 메시지와 사용자 질문 인터랙션을 수행 |
| **글로벌 변수** | `Global.Contact_result` |

{: .highlight }
> Echo Topic에서 토픽의 기본 동작 원리를 배웠습니다. 이번에는 실무에 가까운 **Contact Topic**을 만들어 봅니다. 간단한 메시지와 사용자 질문 인터랙션을 담은 토픽입니다.

## Step-by-Step

### 1. 새 토픽 생성

**토픽** 탭 → **"+ 토픽 추가"** → **"새로 시작"** 클릭

### 2. 이름 & 트리거 설명 입력

- 토픽 이름: `Contact Topic`
- 토픽이 수행하는 작업 설명: `이 토픽은 담당자 이름, 연락처, 이메일을 조회하여 제공합니다`

### 3. 노드 구성 — 메시지와 사용자 인터랙션

간단한 메시지와 사용자 질문 인터랙션을 포함하는 노드를 구성합니다.  
결과는 글로벌 변수 `Global.Contact_result`에 저장하여 오케스트레이터가 활용할 수 있게 합니다.

{: .note }
> 구체적인 실습 이미지와 상세 단계는 추후 제공 예정입니다.

### 4. 저장 및 테스트

- 오른쪽 **저장** 클릭
- 테스트 패널에서 "경비처리 담당자 알려줘"와 같은 질문을 입력하여 Contact Topic이 호출되는지 확인

{: .highlight }
> 파이프라인 정리:  
> 담당자를 찾아달라는 요청 → **Contact Topic 호출** → `Global.Contact_result`에 담당자 정보 저장 → **오케스트레이터가 지침에 따라 해당 정보를 활용하여 답변**
