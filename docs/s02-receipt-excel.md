## 이 모듈에서 만들 것

> **영수증 사진 한 장 → AI가 읽고 분류 → Excel 경비 대장에 자동 행 추가**

S1에서 봤던 “③ AI 빌더 길”의 첫 사례입니다. 단순 요약이 아니라 **다른 시스템(Excel)에 산출물을 흘려보내는 것**이 목적이라 AI 빌더가 필요합니다.

---

## 전체 흐름

```
📸 영수증 사진 (에이전트 대화에서 업로드)
    ↓
🤖 AI 빌더 멀티모달 프롬프트
   "이미지에서 날짜·가맹점·항목·금액 추출"
    ↓
📋 정형 JSON
   { "날짜": "2026-04-01", "가맹점": "스타벅스", "항목": "식비", "금액": 15000 }
    ↓
⚡ Power Automate 흐름
    ↓
📝 Office Script — Excel 테이블 마지막 행에 추가
    ↓
✅ 에이전트 답변: "경비 대장에 추가했습니다"
```

---

## 왜 이 조합인가

| 기술 | 역할 | 비유 |
|:-----|:-----|:-----|
| AI 빌더 멀티모달 | 영수증 이미지를 읽고 이해 | 👀 눈 |
| JSON 출력 | 정해진 형태로 정리 | 📋 정리 |
| Office Script | Excel에 한 줄로 기록 | ✍️ 손 |

{: .highlight }
> 기본과정 M12에서는 **텍스트 대화 내용**을 Excel에 저장했습니다. 여기서는 **이미지를 AI가 읽고 → 정형 JSON → Excel 행**까지 한 번에 자동화합니다.

---

## 두 개의 실습으로 분리

이 모듈은 두 개의 실습으로 나뉩니다.

| 실습 | 주제 | 시간 |
|:----|:-----|:----|
| [실습 ① — AI 빌더 멀티모달 프롬프트](s02-1-receipt-prompt) | 이미지 입력 → JSON 출력 | 20분 |
| [실습 ② — Office Script + 흐름 연결](s02-2-receipt-flow) | JSON → Excel 행 추가 → 에이전트 응답 | 20분 |

**왜 분리하나** — ①은 “AI에게 무엇을 시킬까(프롬프트 설계)”, ②는 “결과를 어디에 흘릴까(시스템 연결)”라는 서로 다른 사고가 필요합니다. 한 모듈로 묶으면 둘 다 흐릿해집니다.

## 산출물 체크리스트

| 항목 | 내용 |
|:-----|:-----|
| AI 빌더 프롬프트 | `ReceiptExtractor` (멀티모달, 입력=이미지, 출력=JSON) |
| Office Script | Excel 경비 대장에 행 추가 |
| Power Automate 흐름 | 에이전트 트리거 → AI 빌더 → Script |
| Excel 파일 | 경비 대장 (날짜·가맹점·항목·금액 4열) |

---

## 기본과정 vs 심화과정 — 데이터 저장

| | 기본과정 (M12) | 심화과정 (S2) |
|:--|:--------------|:-------------|
| 입력 | 텍스트 대화 | **이미지 (영수증)** |
| 처리 | 없음 (그대로 저장) | **AI 멀티모달 분석** |
| 형식 | 시스템 변수 그대로 | **JSON 구조화** |
| 저장 | Excel 행 추가 커넥터 | **Office Script** |
| 활용 | 대화 로그 | **경비 대장 자동화** |
