# 📕 고급과정 — 문과생을 위한 L400 에이전트
{: .fs-9 .no_toc }

MCP 서버를 직접 만들어 에이전트의 백엔드까지 다룬다 — 개발자 지향 1일 과정
{: .fs-6 .fw-300 }

---

{: .warning }
> 이 과정은 **각 수강생에게 할당된 VM과 라이선스**를 사용합니다. M365 계정·비밀번호는 랩 환경에서 강사가 제공합니다. 단, **바이브 코딩**에 쓰이는 GitHub Copilot 또는 ChatGPT(Codex) 계정은 **각자 준비**해야 합니다.

---

---

## 이 과정에서 만나는 것들

| 주제 | 내용 |
|:-----|:-----|
| **MCP (Model Context Protocol)** | 에이전트가 외부 도구를 호출하는 표준 프로토콜 |
| **바이브 코딩** | AI가 코드를 작성하고 사람이 검수하는 개발 방식 (GitHub Copilot / Codex) |
| **Dev Tunnel** | 로컬 서버를 외부에 안전하게 공개하는 VS Code 기능 |
| **MCP Inspector** | MCP 서버가 Copilot Studio 요구사항을 충족하는지 검사하는 도구 |
| **M365 Agent Toolkit** | 프로코드(Declarative Agent) 에이전트를 만들고 배포하는 VS Code 확장 |
