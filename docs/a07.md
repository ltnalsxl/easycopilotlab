# L07. 축하합니다!
{: .no_toc }

MCP 서버를 직접 만들어서, 외부에서 접근 가능하도록 설정하고, Copilot Studio의 로우코드 에이전트와 프로코드 에이전트 양쪽에 연결해봤습니다. 축하드립니다! 이제 여러분은 에이전트의 백엔드가 되는 MCP 서버를 직접 만들고 운영할 수 있는 능력을 갖추게 되었습니다.

앞으로는

- 여러분이 만든 MCP 서버에 다양한 도구들을 추가해서 더 똑똑한 에이전트를 만들거나,
- 여러분의 MCP 서버를 클라우드에 배포해서 24시간 안정적으로 운영하거나,
- 다른 사람들이 만든 MCP 서버를 사용해서 에이전트를 만들 수도 있습니다.

가능성은 무궁무진합니다.
