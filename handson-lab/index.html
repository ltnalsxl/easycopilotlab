Copilot Studio 실습 랩

Microsoft Learn의 Copilot Studio 실습 랩 여섯 개를 한국어로 옮기고, 막히기 쉬운 지점에 설명을 덧붙였습니다. 원문에 실린 화면 이미지를 모두 포함했습니다.

랩 6개 화면 이미지 81장 총 4시간 10분 수준 200
원문을 함께 확인해 주세요

이 문서는 Microsoft Learn 실습 랩 mslearn-copilotstudio를 한국어로 옮기고 설명을 덧붙인 자료입니다. 원문 랩은 영어로만 제공됩니다.

실습 랩은 제품 UI가 바뀌면 수시로 갱신됩니다. 이 문서는 2026년 8월 기준이므로, 화면이 설명과 다르거나 단계가 진행되지 않으면 각 랩 머리의 원문 링크에서 최신 절차를 확인해 주세요. 입력값과 수식은 원문 그대로 옮겼으니 영어 표기 그대로 사용하시면 됩니다.

화면 이미지와 원문 내용의 저작권은 Microsoft에 있습니다.

랩 공통 주의

미리 보기 중인 새 Copilot Studio 환경이 보일 수 있습니다. 랩 00부터 04까지는 현재(표준) 인터페이스를 기준으로 작성됐으므로, 새 환경에서는 단계와 화면이 맞지 않습니다. 랩 05만 새 환경을 씁니다.

랩을 관통하는 핵심 개념

생성형 오케스트레이션이 켜져 있으면 에이전트는 지침, 지식, 토픽, 도구를 조합해 응답을 동적으로 만듭니다. 각 랩은 이 네 가지 중 하나를 깊게 다룹니다.

랩 00 · 환경 준비 10분

원문ILT Setup

랩을 시작하기 전에 작업할 개발 환경을 만듭니다.

연습 1 · Power Platform 환경 만들기

작업 1.1 · 관리 센터 열기

  1. 브라우저에서 https://admin.powerplatform.microsoft.com/manage/environments로 이동해 이 실습용 계정으로 로그인합니다.
  2. 로그인 상태를 유지할지 물으면 유지를 선택합니다.
  3. 표시되는 팝업 메시지를 닫습니다.

작업 1.2 · 기본 환경에 Dataverse 추가

  1. Contoso (default) 환경의 줄임표(...)를 선택하고 Add Dataverse를 선택합니다.
  2. 기본 설정을 그대로 두고 Add를 선택합니다.

작업 1.3 · 새 환경 만들기

  1. Environments 페이지에서 + New를 선택하고 다음처럼 설정합니다.
    • Type · Developer
    • Region · 기본 지역
    • Name · 본인 이름
  1. Change default settings를 펼치고 다음처럼 설정합니다.
    • Environment group · None
    • Make this a Managed Environment · No
    • Get new features early · No
    • Create on behalf · No
    • Add a Dataverse data store? · Yes
  2. Next를 선택하고 Add Dataverse 섹션에서 다음처럼 설정합니다.
    • Language · English (United States)
    • Currency · USD ($)
    • Deploy sample apps and data? · No
  3. Save를 선택하고 환경 상태가 Ready가 될 때까지 기다립니다. Refresh 버튼으로 화면을 갱신할 수 있습니다.
참고

환경 프로비저닝은 테넌트 구성에 따라 몇 분 걸릴 수 있습니다.

  1. 새 브라우저 탭에서 https://copilotstudio.microsoft.com/으로 이동해 로그인합니다.
  2. 메시지가 나오면 Get Started를 선택하고 국가와 지역은 기본값을 유지합니다.
  3. 환영 메시지는 건너뜁니다.
  4. 오른쪽 위 환경 선택기에서 방금 만든 환경으로 전환합니다.
Copilot Studio가 로드되지 않을 때
  1. Power Platform 관리 센터에서 만든 환경을 엽니다.
  2. URL에서 환경 ID(12345678-90ab-cdef-1234-567890abcdef 같은 긴 문자열)를 찾아 복사합니다.
  3. 다음 주소에 붙여 넣어 직접 접근합니다.
    https://copilotstudio.microsoft.com/environments/<환경ID>/home

작업 1.4 · 솔루션 만들기

  1. 왼쪽 탐색 창에서 줄임표(...)를 선택하고 Solutions를 선택합니다.
  2. Default Solution과 Common Data Services Default Solution을 포함한 솔루션 목록이 보입니다.
  1. + New solution을 선택합니다.
  2. Display name에 Lab Exercises를 입력합니다.
  3. Name이 자동으로 채워졌는지 확인합니다.
  4. Publisher 드롭다운 아래 + New publisher를 선택합니다.
  5. Display name에 Fabrikam, Name에 fabrikam, Prefix에 fab을 입력합니다.
  6. Save를 선택해 게시자를 만듭니다.
  7. Publisher 드롭다운에 Fabrikam (fabrikam)이 선택됐는지 확인합니다.
  8. Set as your preferred solution 확인란을 선택합니다.
왜 기본 솔루션으로 지정하나

이후 랩에서 만드는 자산이 자동으로 Lab Exercises 솔루션에 들어갑니다. 나중에 한꺼번에 옮기거나 지우기 쉬워집니다.

  1. Create를 선택합니다.
  2. Solutions 브라우저 탭을 닫습니다.
  3. Copilot Studio 페이지를 새로 고칩니다.

이제 작업할 Power Platform 환경과 솔루션이 준비됐습니다.

랩 01 · Copilot Studio로 에이전트 만들기 45분

원문Create agents with Copilot Studio
이 랩에서 하는 일

  • 공개 웹사이트를 지식 원본으로 추가하기

연습 1 · Safe Travels 템플릿으로 만들기

작업 1.1 · 템플릿에서 에이전트 만들기

  1. Copilot Studio 홈에서 왼쪽 탐색의 Agents를 선택합니다.
  2. 페이지 상단에서 이 실습에 쓸 환경이 맞는지 확인합니다.
  3. Start with an agent template 아래 Safe Travels 템플릿을 선택합니다.
  1. 오른쪽 위 줄임표(...)에서 Edit advanced settings를 선택합니다.
  2. 선택된 Solution이 Lab Exercises, Schema name 접두사가 fab인지 확인하고 Cancel을 선택합니다.
  3. 오른쪽 위 Create를 선택합니다.
  4. Overview 탭에서 이름, 설명, 지침을 살펴봅니다.
  5. Knowledge 탭에서 지식 원본으로 추가된 공개 웹사이트를 확인합니다.
  6. 오른쪽 위 Settings를 선택합니다.
  7. Orchestration이 No · 클래식 오케스트레이션 사용, 응답을 토픽에 정의된 내용과 동작으로 제한으로 설정돼 있는 것을 확인합니다.
  8. 설정 페이지 오른쪽 위 X로 설정을 닫습니다.
  9. Topics 탭을 선택하고 System 필터를 적용합니다.
  10. Conversation Start 토픽을 선택합니다. Message 노드 내용을 확인하고, 그 내용이 Test 창에 그대로 표시되는 것을 봅니다.
  1. 왼쪽 위 드롭다운에서 사용자 지정 토픽 What can I ask를 선택합니다.

작업 1.2 · 에이전트 테스트

  1. Test 창이 안 보이면 오른쪽 위 Test 아이콘을 선택합니다.
  2. Test 창에서 변수 {x} 아이콘 옆 줄임표(...)를 선택하고 Track between topics를 On으로 켭니다.
  1. 다음 프롬프트를 입력합니다.
프롬프트Hello

Greeting 토픽이 선택되고, 그 토픽의 메시지 노드에서 응답이 나옵니다.

  1. Test 창 위쪽 Start new test session 아이콘 +를 선택합니다.
  2. 다음 프롬프트를 입력합니다.
프롬프트What can I ask?

What Can I Ask 토픽이 트리거되고 대화를 이어갈 몇 가지 선택지가 나옵니다.

  1. How do I get a passport? 옵션을 선택합니다. 설정된 지식 원본으로 응답이 생성되고, Conversational boosting 시스템 토픽이 참조될 수 있습니다.
  1. 다음 프롬프트를 입력합니다.
프롬프트What is Copilot Studio?

Fallback 토픽이 선택되고, 에이전트가 다시 말해 달라고 요청합니다.

  1. 같은 프롬프트를 두 번 더 반복합니다. 환경과 오케스트레이션 동작에 따라 Fallback이나 Escalate 시스템 토픽이 트리거될 수 있습니다.
  2. 왼쪽 탐색에서 Agents를 선택합니다. Safe Travels 에이전트가 목록에 있어야 합니다.

연습 2 · Copilot으로 에이전트 만들기

자연어로 미국 정부 복지 혜택 문의에 답하는 에이전트를 만듭니다.

작업 2.1 · 에이전트 생성

  1. Copilot Studio 홈에서 만든 환경에 있는지 확인합니다.
  2. 왼쪽 탐색에서 Agents를 선택합니다.
  3. Start building by describing what your agent needs to do 텍스트 상자 왼쪽 아래에서 톱니바퀴 모양의 Agent Settings 아이콘을 선택합니다.
  1. 기본 언어는 English (United States)로 둡니다.
  2. Solution 드롭다운에서 Lab Exercises를 선택합니다.
  3. Schema name에 govbenefitsagent를 입력합니다.
  4. Update를 선택합니다.
  5. 텍스트 상자에 다음 프롬프트를 입력합니다.
프롬프트You are an agent that assists with questions related to claiming US government benefits.
  1. Send 아이콘을 선택하면 에이전트가 만들어집니다.

작업 2.2 · Overview 탭 설정

  1. Overview 탭을 선택합니다.
  2. Details 섹션에서 Edit를 선택합니다.
  3. Name에 US Benefits Assistant를 입력합니다.
  4. Description에 Helps users with questions related to US government benefit programs를 입력합니다.
  5. Save를 선택합니다.
  6. Select your agent's model 섹션에서 가능하면 GPT-5 Auto (Preview)를 선택합니다. 없으면 기본 모델을 그대로 둡니다.
  7. Instructions 섹션에서 Edit를 선택합니다.
  8. 지침의 # General Guidelines 아래에 다음 줄을 추가합니다.
추가할 지침- Do not provide legal advice.
  1. Save를 선택합니다.
참고

지침은 에이전트가 어떻게 행동해야 하는지 안내할 뿐, 동작을 엄격하게 강제하지는 않습니다. 뒤 랩에서 토픽, 지식, 지식 원본을 제한한 생성형 답변으로 동작을 바꾸는 방법을 배웁니다.

  1. Suggested prompts 섹션에서 + Add suggested prompts를 선택합니다.
  2. Title에 Health, Prompt에 What health assistance programs are available for me?를 입력합니다.
  3. Save를 선택합니다.

작업 2.3 · 공개 웹사이트를 지식 원본으로 추가

  1. Knowledge 탭을 선택합니다.
  1. + Add knowledge를 선택합니다.
  2. Public websites를 선택합니다.
  3. Public website link에 https://www.usa.gov/benefits를 입력합니다. 복지 프로그램 정보가 담긴 공식 정부 사이트입니다.
  4. Add를 선택합니다.
  5. Name에 Government benefits를 입력합니다.
  6. Description에 다음을 입력합니다.
설명This knowledge source contains information on government programs that may help you pay for food, housing, health care, and other basic living expenses.
  1. Add to agent를 선택합니다.
참고

공개 웹사이트 색인은 몇 분 걸릴 수 있습니다. 응답이 불완전하면 몇 분 기다렸다가 다시 테스트하세요.

작업 2.4 · 에이전트 설정

  1. 오른쪽 위 Settings를 선택합니다.
  2. Orchestration이 Yes · 응답이 동적으로 생성되며 필요에 따라 도구와 지식을 사용으로 설정된 것을 확인합니다.
  3. Responses 섹션에 다음을 입력합니다.
응답 지침- For process related answer respond with a single sentence. - For data-related answers respond with bullet points.
  1. Knowledge 섹션에서 Allow ungrounded responses를 Off로 설정합니다.
  2. 같은 섹션에서 Use information from the Web을 On으로 설정합니다.
  3. Save를 선택합니다.
  4. 설정 페이지 왼쪽에서 Security를 선택합니다.
  5. Authentication을 선택합니다.
  6. 데모 웹사이트 채널에서 테스트하기 쉽도록 No authentication을 선택합니다.
  7. Save를 선택하고 한 번 더 Save를 선택합니다.
  8. 오른쪽 위 X로 설정을 닫습니다.
왜 인증을 끄나

데모 웹사이트는 인증이 Authenticate with Microsoft일 때 쓸 수 없습니다. 이 랩에서만 편의를 위해 끄는 것이고, 실제 운영에서는 그대로 두면 안 됩니다.

작업 2.5 · 테스트

  1. 오른쪽 위 Test 아이콘으로 테스트 창을 엽니다.
  2. 변수 {x} 아이콘 옆 줄임표에서 Show activity map when testing을 On, Track between topics를 Off로 설정합니다.
  1. Test 창 위쪽 +로 새 세션을 시작합니다.
  2. 다음 프롬프트를 입력합니다.
프롬프트What health insurance information is available?

활동 맵이 표시되고, 응답 생성에 지식 원본이 쓰였다는 것이 보입니다.

  1. 테스트 창을 닫습니다.

작업 2.6 · 데모 웹사이트에 게시

  1. 동작 표시줄에서 Publish를 선택하고 한 번 더 Publish를 선택합니다.
  2. Channels 탭을 선택합니다.
  1. Demo website 채널을 선택합니다. 에이전트 경험을 빠르게 확인하기 좋은 채널입니다.
  2. 다음처럼 설정합니다.
    • Welcome message · Ask me about government benefit programs
    • Conversation starters · 아래 세 줄
대화 시작 문구"Hello" "What programs am I entitled to?" "What is social security?"
  1. Save를 선택합니다.
  2. Open demo website를 선택합니다.
  3. 다음 프롬프트를 입력합니다.
프롬프트What welfare and assistance can I claim for?

중요

새 Copilot Studio 환경은 기존 토픽 작성 캔버스를 대체하는 새 인터페이스입니다. 이 랩의 단계와 화면은 새 환경 기준입니다. 환경이 기존 인터페이스로 보인다면 안내에 따라 새 환경으로 전환한 뒤 진행하세요.

핵심 개념 · 지침 기반 에이전트

새 환경은 토픽 작성 캔버스를 더 단순한 지침 기반 모델로 대체합니다.

기존 환경새 환경
토픽 트리와 트리거 문구로 동작 정의자연어 지침으로 동작 정의
제작자가 노드 하나씩 대화 흐름을 만듦에이전트가 응답 방법을 동적으로 추론
토픽, 조건, 분기가 대화 경로를 통제지침, 지식, 동작이 할 일을 결정
동작을 쓰려면 Power Automate 워크플로를 만들고 입출력을 설정한 뒤 도구로 추가사전 제작 커넥터 동작을 Copilot Studio에서 바로 추가. 워크플로 작성이 필요 없음

새 환경은 열린 결말의 맥락 의존적 대화에 잘 맞습니다. 기존 환경은 순서가 보장되고 감사 가능한 단계가 필요할 때, 예를 들어 정해진 순서로 구조화된 데이터를 수집할 때 여전히 적합합니다.

연습 1 · 새 환경으로 전환

  1. https://copilotstudio.microsoft.com/으로 이동해 로그인합니다.
  2. 페이지 상단에서 쓸 환경이 맞는지 확인합니다.
  3. Try the new experience 배너나 알림이 보이면 선택합니다. New experience 토글이 안 보이면 https://copilotstudio.preview.microsoft.com/으로 직접 이동합니다.
참고

환경에 따라 새 환경이 이미 기본일 수 있습니다. 화면이 이 랩 단계와 이미 맞는다면 새 환경을 쓰고 있는 것이니 연습 2로 넘어가세요.

작업 1.2 · 새 인터페이스 살펴보기

  1. 왼쪽 탐색의 주요 항목을 확인합니다. Home, Agent Ops, Chat, Agents, Workflows입니다.
  2. Agents 페이지에 기존 에이전트가 보입니다. 새 환경에서 만든 에이전트에는 토픽 캔버스가 없고, 동작은 전부 Overview 페이지의 지침, 지식, 동작으로 정의됩니다.
  3. 탐색에 Topics 섹션이 없다는 점을 확인합니다. 새 환경에서 토픽은 동작과 지침으로 대체됩니다.

연습 2 · 에이전트 만들기

Contoso라는 가상 회사의 IT 지원 에이전트를 만듭니다. 흔한 IT 문제 해결을 돕고, 해결이 안 되면 지원 티켓 제출을 돕습니다.

작업 2.1 · 에이전트 생성

  1. 왼쪽 탐색에서 Home을 선택합니다.
  2. 빌드 프롬프트 상자에 다음 설명을 입력합니다.
프롬프트You are an IT support agent for Contoso. You help employees troubleshoot common IT issues such as password resets, software installation problems, and network connectivity. When you cannot resolve an issue, you help the employee submit a support ticket.
참고

새 환경은 이 설명을 바탕으로 초기 지침 묶음을 자동 생성합니다. 계속하기 전에 내용을 확인하세요.

  1. 확인 질문이 나오면 더 정확한 지침이 만들어지도록 답합니다. 예를 들어 다음과 같습니다.
    • 직원이 IT 지원 티켓을 어떻게 제출하는지 물으면, ServiceNow나 Jira, Dynamics 365, Zendesk가 아니라 IT 헬프데스크로 지원 요청 메일 보내기를 고릅니다.
    • 기술 문서나 SharePoint 사이트, 웹사이트를 참조할지 물으면 외부 지식 원본이 필요 없다는 쪽을 고릅니다.
  2. 질문을 넘길 때는 Continue, 해당 없는 질문은 Skip, 끝나면 Submit을 선택합니다.
참고

설명과 환경에 따라 확인 질문이 다르게 나오거나 아예 안 나올 수 있습니다. 정확히 이 질문과 선택지를 기대하지 말고, 랩 시나리오에 맞게 답하세요.

  1. 지원 요청을 보낼 메일 주소를 물으면 관리자 메일 주소를 입력하고 Submit을 선택합니다.
  2. 자동 생성된 지침을 확인하고 수락해 에이전트를 만듭니다.
  3. 오른쪽 Artifacts 패널에서 에이전트를 선택해 Build 탭을 엽니다.

작업 2.2 · 지침 확인하고 다듬기

  1. Build 탭에서 Instructions 섹션을 찾습니다.
  2. 설명에서 생성된 지침을 읽어 봅니다. 목적, 어조, 일반 동작이 담겨 있어야 합니다.
  3. 다음 지침을 추가하고 Save를 선택합니다.
추가할 지침## Guidelines - Always respond in a professional and friendly tone. - For password reset requests, direct the employee to the self-service portal at https://aka.ms/sspr before offering to raise a ticket. - For issues you cannot resolve, collect the employee's name, email address, and a brief description of the issue before submitting a ticket. - Do not speculate about hardware failures. Always recommend contacting the IT desk directly for physical hardware issues. - When an employee's issue cannot be resolved, use the Send an email action to notify the IT helpdesk at helpdesk@contoso.com with the employee's name, email, and issue description.
참고

새 환경에서 지침은 동작을 통제하는 주된 수단입니다. 지침을 잘 쓰면 추가 설정이 줄고 에이전트가 더 예측 가능해집니다.

연습 3 · 테스트하고 다듬기

작업 3.1 · Preview 탭 열기

  1. 페이지 위쪽 Preview 탭을 선택해 에이전트를 테스트합니다.
  2. 테스트하면 각 응답 위에 추론 요약이 자동으로 나타나 에이전트가 무엇을 어떻게 판단했는지 알려 줍니다. Show more를 선택하면 전체 추론 추적이 펼쳐집니다.
추론 추적이 왜 중요한가

새 환경의 핵심 기능입니다. 어떤 지식 원본이나 동작을 고려했고 왜 그랬는지 보여 줍니다. 예를 들어 Loaded Skill 항목은 어떤 동작이나 스킬을 호출했는지 알려 줍니다.

작업 3.2 · 지침 테스트

  1. Preview 탭 위쪽에서 New chat을 선택합니다.
  2. 다음 프롬프트를 입력합니다.
프롬프트I forgot my password and cannot log in.

작성한 지침에 따라 에이전트는 티켓을 제안하기 전에 셀프서비스 포털로 안내해야 합니다.

작업 3.3 · 추론 동작 테스트

  1. New chat을 선택합니다.
  2. 다음 프롬프트를 입력합니다.
프롬프트My laptop will not turn on at all.

작성한 지침에 따라 에이전트는 하드웨어 고장을 원격으로 진단하기를 거절하고 IT 데스크에 직접 연락하도록 권해야 합니다. 대신 지원 티켓 제출을 제안할 수도 있습니다.

  1. 요청하면 이름, 메일 주소, 문제에 대한 짧은 설명을 제공합니다.

작업 3.4 · 결과를 보고 지침 다듬기

  1. 세 번의 테스트 세션에서 에이전트가 어떻게 응답했는지 살펴봅니다.
  2. 의도와 다른 응답이 있었다면 Build 탭의 Instructions에서 해당 지침을 손봅니다. 예를 들어 셀프서비스 포털을 언급하지 않았다면 더 명시적으로 씁니다.
더 명시적인 지침- For ALL password-related requests, always mention https://aka.ms/sspr as the first step before any other assistance.
  1. Publish, 이어서 Save and Publish를 선택하고 해당 시나리오를 다시 테스트합니다.
참고

지침을 반복해서 다듬는 것이 새 환경의 주된 튜닝 방법입니다. 표현을 조금만 바꿔도 동작이 크게 달라집니다.

랩 05 요약

새 환경으로 지침 기반 IT 지원 에이전트를 만들었습니다. 동작을 전부 자연어 지침으로 설정하고, 사전 제작 커넥터 동작을 Power Automate 워크플로 없이 바로 추가했습니다. 워크플로를 만들고 입출력을 설정하고 따로 게시해야 했던 랩 04와 비교하면, 단순한 동작에 드는 제작 노력이 크게 줄어듭니다. Preview 창의 추론 추적으로 에이전트가 응답 전에 무엇을 판단했는지도 확인했습니다. 이제 두 환경을 모두 겪었으니 상황에 맞게 고를 수 있습니다. 열린 대화에는 지침 기반, 순서가 보장되고 감사 가능한 단계가 필요하면 기존 토픽과 워크플로입니다.

문제 해결 모음

증상해결
Copilot Studio가 내 환경에서 로드되지 않는다관리 센터 URL에서 환경 ID를 복사해 https://copilotstudio.microsoft.com/environments/<환경ID>/home으로 직접 접근합니다.
커넥터 로그인 팝업이 차단된다주소 표시줄의 팝업 차단 아이콘에서 copilotstudio.microsoft.com의 팝업을 항상 허용합니다.
업로드한 파일로 답을 못 한다Knowledge 탭에서 상태가 Ready인지 확인합니다. 색인에 10분 이상 걸릴 수 있습니다.
공개 웹사이트 답변이 불완전하다색인이 끝날 때까지 몇 분 기다렸다가 다시 테스트합니다.
에이전트가 토픽이나 도구를 안 부른다지침에서 토픽과 도구를 /로 삽입한 참조로 넣었는지 확인하고 새 테스트 세션을 시작합니다.
워크플로 입력에서 형식 오류가 난다선택(choice) 값을 텍스트로 바꿔야 합니다. Text(Global.변수명) 수식을 씁니다.
데모 웹사이트 링크가 없다인증이 Authenticate with Microsoft이면 쓸 수 없습니다. No authentication이나 수동 인증으로 바꿉니다.
Edit with Copilot이 노드를 잘못 고쳤다Undo를 누르고 다른 표현으로 다시 시도합니다.
화면이 랩 설명과 다르다랩 00~04는 표준 인터페이스 기준입니다. New experience 토글을 끄세요.
